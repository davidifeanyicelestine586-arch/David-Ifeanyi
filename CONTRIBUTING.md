# Contributing

Thanks for helping improve this portfolio repository.

- Keep factual portfolio claims accurate and verifiable.
- Do not add fabricated experience, metrics, credentials, or client claims.
- Do not commit secrets, credentials, or private project artifacts.
- Keep project descriptions consistent with the relevant source repository and verified live work.
- Run the project's available checks before submitting changes.

For pull requests, explain the change and note any verification performed.

Contributions are provided under the repository's MIT License.
